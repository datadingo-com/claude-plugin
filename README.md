# DataDingo plugin for Claude Code

Australian company data for your AI: find businesses by industry, size, location and the technology
they use, find companies like your best customers, and see what they've announced lately. This
plugin connects Claude Code to DataDingo's MCP server (`https://mcp.datadingo.com/`).

## Install

```
claude plugin marketplace add datadingo-com/claude-plugin
claude plugin install datadingo
```

Then run `/mcp`, choose **datadingo** and **Authenticate**. Sign-in is one browser tab: your email
and a code (or Google), then Allow.
