# DataDingo plugin for Claude Code

Australian company data for AI agents. This plugin connects Claude Code to DataDingo's MCP server
(`https://mcp.datadingo.com/`), so you can look up and search every registered Australian
business: ABN, ACN, entity status, website, industry and locations.

## Install

```
claude plugin marketplace add farnell/datadingo-claude-plugin
claude plugin install datadingo@datadingo
```

Then run `/mcp`, choose **datadingo** and **Authenticate**. Sign-in is one browser tab: your email
and a code (or Google), then Allow.

## Costs

Search and result counts use no credits on an active account. A full company record costs 1
credit the first time your account gets it. Credits: https://app.datadingo.com/buy
